版本 1.1.5（修订 2）

工业监控 · 使用说明书

软件名称： 工业监控（HuaGuang Monitor） 当前版本： 1.1.5（修订 2） 适用平台： Windows 10/11 工控机、Android 11 工业平板

1. 软件简介

工业监控用于 热熔胶复合机 等产线的现场数据采集与远程查看：

  • 采集模式：按设定周期从信捷 XD5E-60T10 PLC 读取温度、车速等点位，组装为 JSON 后通过 MQTT 上报。
  • 订阅模式：连接同一 MQTT Broker，订阅已配置主题，在局域网内查看其他设备上报的遥测数据。

同一套程序可在 Windows 工控机与 Android 平板上运行，界面与配置基本一致。

2. 系统要求与安装

2.1 系统要求

平台 要求
Windows Windows 10 1809 及以上 64 位（含 Win10 21H2/22H2、Windows 11）
Android Android 11（API 30）工业平板推荐；最低 Android 7.0（API 24）

2.2 Windows 安装

  1. 双击 IndustrialMonitor-1.1.5-r2-Setup.exe（或当前版本对应安装包）。
  2. 按向导完成安装，默认目录为 C:\Program Files\IndustrialMonitor。
  3. 安装时可勾选：
  • 桌面快捷方式
  • 开机自动启动（登录 Windows 后自动运行程序）
  1. 卸载：通过「程序和功能」卸载；卸载时可选择是否删除本地用户数据。

2.3 Android 安装

  1. 将 IndustrialMonitor-1.1.5-r2-android.apk 拷贝到平板（U 盘或数据线；勿用微信传 APK，易损坏）。
  2. 在平板设置中允许「安装未知来源应用」。
  3. 用文件管理器打开 APK 完成安装。
必须使用带 -Signed 后缀的已签名 APK，否则可能提示「安装包似乎无效」。

4. 快速上手

4.1 无 PLC 时验证软件（模拟数据）

适用于办公室调试、验证 MQTT 是否正常：

  1. 打开 设置。
  2. 运行模式 选 采集模式。
  3. 勾选 使用模拟数据。
  4. 填写 MQTT Broker 地址与端口（本地测试可用 127.0.0.1:1883）。
  5. 点 保存设置。
  6. 进入 监控，点 启动采集。
  7. 界面应显示模拟温度、车速等数据；若 Broker 可达，远端可收到 JSON 遥测。
模拟模式下不会连接 PLC，PLC 状态显示为未连接，属正常现象。

4.2 连接现场 PLC 采集

  1. 在 XDPpro 中为 PLC 开启 Modbus TCP Server，端口 502，站号 1。
  2. 确认 PLC 与工控机/平板在同一网段。
  3. 设置 中：
  • 取消勾选 使用模拟数据
  • 填写 PLC IP（先河默认 192.168.6.10，华迪默认 192.168.6.20）
  • 填写 MQTT Broker 信息
  • 扫描周期 建议 60000（60 秒）
  1. 保存后，在 监控 页点 启动采集。
  2. 观察 PLC 状态为 已连接，各点位数值与更新时间按周期刷新。

4.3 订阅模式查看远程设备

  1. 设置 → 运行模式 选 订阅模式。
  2. 添加订阅主题（支持 +、# 通配符），例如两条产线默认主题。
  3. 保存设置，在 监控 点 启动订阅。
  4. 首页 主题筛选 可选「全部」或单个主题；有数据后可在 设备 列表中选择查看。

5. 监控页

5.1 顶栏与状态

  • 设备编号 / 运行模式：显示当前设备 ID 及「采集模式 · 模拟数据 / PLC 实采」或「订阅模式」。
  • PLC / MQTT 指示灯：
  • 绿点 +「已连接」：对应通道正常。
  • 灰点 +「未连接」：未连接或模拟模式下 PLC 未使用。
  • 启动采集 / 停止采集（或 启动订阅 / 停止订阅）：控制后台采集或订阅任务。

采集运行中，模式行还会显示：

  • 周期：当前扫描间隔（秒）
  • 读 / PLC：本轮读点耗时（秒）
  • 等：距下一轮开始的等待时间（秒）
  • 待发送 N：MQTT 队列中尚未发出的条数（Broker 暂不可达时出现）
  • 刷新 HH:mm:ss：最近一次界面数据刷新时刻

5.2 数据卡片

点位按 显示分组 分块展示（温度、工艺、设定值、开关等），每张卡片显示：

  • 名称、数值、单位
  • 数据质量（绿点 Good / 红点 Bad）
  • 最后更新时间

开关类（如「运行状态」）以圆形指示器显示开/关。

5.3 手动输入点位

部分点位不读 PLC，需在界面手工维护，例如：

名称 说明
胶辊型号 文本，点击卡片可修改
胶水型号 文本，点击卡片可修改
产品货号 文本，MQTT 字段 cphh
门幅 / 厚度 数值，带单位 mm

产品货号 · USB 扫码枪

  1. 在 监控 页点击 产品货号 卡片（提示「点击扫码」）。
  2. 底部弹出输入栏。
  3. 使用 Mexxen 等 USB 扫码枪（键盘模式）扫描条码，扫完自动回车；或手工输入后按回车 / 点 确认。
  4. 确认后立即触发一次 MQTT 上报（若 Broker 可用）。
  5. 点 取消 关闭输入栏。

5.4 底栏

显示最近 MQTT 报文摘要、发布说明（如温度未达阈值未发布）、错误信息等。

6. 点位页

6.1 列表

  • 按产线 Excel 中的 显示分组 分组列出所有点位。
  • 每张卡片显示：名称、分组、信捷地址、来源（PLC/手动）、MQTT 字段、是否启用。
  • 可 编辑 或 删除 点位；顶栏 新增 可添加自定义点位。

6.2 编辑点位

项目 说明
信捷地址 如 D6000、M0、X20（X/Y 为八进制，X7 下一个是 X10）
数据类型 浮点、整数、布尔等；浮点占两个 D，默认字节序 CDAB
Scale / Offset 工程量换算
显示精度 0–4 位小数；留空则用设置页全局精度
显示分组 控制监控页分组与卡片颜色
MQTT 字段 上报 JSON 中的键名
手动值 仅手动输入点位可填
产线整体切换、从 Excel 批量载入请在 设置 页操作；日常单个点位修改在本页完成。

7. 历史页

7.1 启用记录

在 设置 → 历史数据 中：

  • 勾选 记录采集/订阅数据到本地 SQLite
  • 设置 保留天数（1–365，默认 14 天；超期记录在程序启动时自动清理）

7.2 查询

  1. 进入 历史 Tab（不会自动加载）。
  2. 选择 时间范围：
  • 最近 24 小时 / 7 天 / 30 天
  • 自定义时间：勾选开始和/或结束日期时间，可只设一端
  1. 可选 设备 筛选。
  2. 点 刷新 加载数据。
  3. 表格展示时间、设备、各点位值；下滑或点 加载更多 分页浏览（每页 40 条）。

7.3 删除

  • 删：删除单条记录
  • 删除筛选：删除当前筛选条件下全部记录
  • 清空全部：删除所有历史

修改筛选条件后需再次点 刷新。

8.4 产线 Excel

每条产线一个 .xlsx，含工作表：配置、MQTT报文、字段映射、点表、显示分组说明。

  • 从 Excel 载入产线：按当前所选产线读取
  • 保存当前配置到 Excel：将设置写回文件
  • 从其他 Excel 文件导入：选择外部 xlsx 覆盖当前产线配置

文件位置：程序目录 config/lines/ 或用户数据目录 lines/。

建议停止采集/订阅后再修改 PLC、MQTT 或导入 Excel（运行中在首页添加订阅主题除外）。

9. 诊断页

  • 显示 版本号与修订号。
  • 点 核心测试 运行内置自检（Modbus 地址解析、MQTT 映射、Excel 读写、历史存储等）。
  • 现场遇到异常时可先运行自检，将 FAIL 项反馈给维护人员。

10. 工作原理说明（帮助理解界面计时）

10.1 采集周期

每一轮采集的顺序为：

  1. 读 PLC（或生成模拟数据）→ 立即刷新监控页
  2. 若满足发布条件，将 MQTT 报文 放入发送队列（不阻塞读点）
  3. 等待至下一个扫描周期开始

因此：

  • 界面刷新 按扫描周期进行，不受 MQTT 是否连通影响。
  • MQTT 发送 在后台独立线程完成；Broker 暂时不可达时，报文最多缓存 128 条，首页显示 待发送 N，恢复后自动补发。

10.2 模拟模式

  • 不连接、不读取 PLC。
  • 若之前连过 PLC，进入模拟模式后会自动断开。
  • 适合无现场设备时调试界面与 MQTT。

11. 常见问题

Q1：界面显示「周期 60 秒」，但刷新很慢？

  1. 确认 设置 → 扫描周期 为 60000，保存后 停止再启动 采集。
  2. 若使用 模拟数据，Broker 不通时首轮可能稍慢，之后应正常；观察 等 是否接近 60 秒。
  3. 查看 待发送 N：若 N 持续增大，检查 MQTT Broker 地址、端口、账号。

Q2：PLC 显示未连接？

  1. 确认未勾选 使用模拟数据。
  2. 检查 IP、网线、PLC 上 Modbus TCP 是否开启。
  3. 用 XDPpro 确认 PLC 与电脑同网段、端口 502。
  4. 查看监控页红色 错误信息。

Q3：MQTT 显示未连接，但数据在刷新？

采集与 MQTT 已分离：读点与界面刷新不依赖 MQTT。请检查 Broker 配置；连接成功后 待发送 队列会自动清空。

Q4：温度有变化但 MQTT 未每次上报？

检查 温度发布阈值：大于 0 时只有温度变化达到阈值才发布（最长间隔仍为一个扫描周期）。设为 0 则每次扫描都发布。

Q5：产品货号扫不上？

  1. 确认扫码枪为 USB 键盘模式（扫完自动回车）。
  2. 先点击 产品货号 卡片，待输入栏弹出后再扫描。
  3. 扫完按回车或点 确认。

Q6：历史页没有数据？

  1. 在 设置 中开启 记录采集/订阅数据。
  2. 进入历史页后须手动点 刷新。
  3. 确认时间范围、设备筛选是否过窄。

Q7：Android 平板安装失败？

  • 使用 Signed 签名 APK。
  • 勿经微信传输；改用 U 盘或 adb install。

12.4 MQTT 报文示例

默认产线（先河 / 华迪）使用 properties 扁平容器 报文：所有点位值放在 properties 对象内，键名为 MQTT 字段（见字段映射表），不包含 deviceId、timestamp、quality 等根级元数据。

发布主题（先河）： /RRJFHJ/XHRRJFHJ/properties/report

报文示例（节选）：

{
  "properties": {
    "run_status": 1,
    "rrjwd1": 180.5,
    "jgwd1": 175.2,
    "jqwd1": 174.8,
    "speed": 45.2,
    "jqzl": 12.3,
    "cphh": "ABC12345",
    "胶辊型号": "A型",
    "胶水型号": "HM-001",
    "门幅": 1200,
    "厚度": 0.12
  }
}
说明 内容
根结构 仅 properties 一层（可在 Excel「MQTT报文」工作表修改 TagsPath）
布尔量 运行状态 映射为 run_status，值为 0 或 1（非 true/false）
温度 / 模拟量 键为映射字段（如 rrjwd1），数值按点位或全局精度四舍五入
手动输入 有映射的用字段名（如 cphh）；未映射的用点位中文名作键（如 胶辊型号）
设备编号 不在 JSON 内；设备身份由发布主题与 Broker 侧配置区分
